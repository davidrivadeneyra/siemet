# Instrucciones del proyecto SIEMET

## Decisiones del proyecto

Antes de diseñar, planificar o implementar el sitio, lee `decisiones-web-siemet.md` y respeta sus decisiones como requisitos del proyecto.

## Acceso a diseños de Figma

Cuando el usuario proporcione un enlace de Figma, usa siempre las herramientas MCP de Figma para acceder al archivo y al nodo indicado. Lee su estructura, componentes, propiedades, estilos y variables mediante el MCP; no te limites a interpretar la vista previa, capturas o frames adjuntos.

Si el MCP de Figma no está disponible, no está conectado o no tiene autorización para acceder al archivo, indícalo claramente antes de continuar. No sustituyas silenciosamente el acceso MCP por una interpretación visual del enlace.
